# AI Background Removal Web App

A full-stack web application that allows users to upload images and automatically remove the background using an AI API. The platform includes authentication, a credit-based usage system, and Razorpay payment integration.


## Tech Stack

Frontend:
- React
- HTML
- CSS
- JavaScript

Backend / APIs:
- Node.js
- Express

AI Integration:
- Background Removal API

Payments:
- Razorpay API

Authentication:
- JWT / Session-based login


## Features

- User signup and login
- Upload image for background removal
- AI-powered background removal
- Credit-based usage system
- Razorpay payment integration
- Download processed images


## How It Works

1. User creates an account and logs in.
2. Uploads an image to the platform.
3. The image is sent to the background removal API.
4. The processed image is returned and displayed.
5. Each request consumes credits.
6. Users can purchase more credits using Razorpay.
